# Front-end — Contribuições

Este diretório contém o **front-end** do projeto.  
Atualmente, o desenvolvimento principal é focado no **back-end**, portanto **contribuições para o front-end são muito bem-vindas**.

Se você é desenvolvedor(a) front-end e quer colaborar em um projeto real, este espaço é para você.

---

## 🎯 Objetivo do Front-end

O front-end tem como objetivo:

- Consumir a API já existente
- Fornecer uma experiência clara, simples e consistente
- Evoluir a interface conforme novas funcionalidades do back-end surgem

O back-end já está estruturado com:

- autenticação
- controle de acesso (roles)
- regras de domínio bem definidas

Ou seja: **há bastante espaço para criação e decisões de UI/UX no front-end**.

---

## 🤝 Como você pode contribuir

Algumas formas diretas de contribuição:

- Implementar telas a partir das rotas já existentes
- Melhorar UI/UX (layout, acessibilidade, feedbacks)
- Padronizar componentes
- Criar fluxos de autenticação e autorização no front-end
- Integrar corretamente estados de loading, erro e sucesso
- Sugerir melhorias de arquitetura front-end

Se você gosta de **tomar decisões técnicas e visuais**, aqui você terá autonomia.

---

## 🧩 Escopo atual aberto para contribuições

Exemplos de áreas que precisam (ou podem) ser trabalhadas:

- Autenticação (login / refresh / logout)
- Fluxo de hábitos
- Listagem e visualização de dados
- Tratamento de erros vindos da API
- Estados vazios (empty states)
- Experiência mobile-first (se aplicável)

Nada aqui é “engessado”.

---

## 🛠️ Liberdade técnica

O front-end **não está fechado em decisões definitivas**.

Contribuições são bem-vindas para:

- estrutura de pastas
- organização de componentes
- padrões de estado
- estratégias de consumo da API

Desde que:

- sejam bem justificadas
- mantenham o código legível
- não quebrem o contrato com o back-end

---

## 📌 Comunicação

Caso queira contribuir:

- Abra uma issue descrevendo a ideia
- Ou abra diretamente um PR explicando o que foi feito e por quê
- Discussões técnicas são bem-vindas

A ideia é **colaborar**, não apenas “entregar código”.

---

## 🧠 Filosofia do projeto

- Código claro > código complexo
- Decisões explícitas > mágicas
- Evolução constante > perfeição inicial

Se você compartilha dessa mentalidade, sua contribuição será muito bem recebida.

---

## ✨ Considerações finais

Mesmo sendo um projeto mantido principalmente por uma pessoa no back-end,  
o front-end **não é secundário** — ele é parte essencial da experiência.

Se quiser ajudar a construir isso, fique à vontade para contribuir 🚀
